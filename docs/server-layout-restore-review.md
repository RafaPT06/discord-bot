# Review checklist

- Safety snapshot is created before edits.
- Merge never deletes extras.
- Replace requires exact server name.
- Managed roles are preserved.
- Categories are created before children.
- Recreated role IDs are used by channel overrides.
- Recreated category IDs are used by child channels.
- Per-server concurrent execution is rejected.
- Execution report contains the safety snapshot and ID maps.
